# TaskFlowUAM

📱 TaskFlowUAM

📌 Descripción del proyecto

TaskFlowUAM es una aplicación móvil desarrollada en Android que permite gestionar tareas de manera sencilla e intuitiva.
El usuario puede crear, editar, eliminar y marcar tareas como completadas, además de organizarlas mediante filtros, prioridades y fechas de entrega.

La aplicación fue desarrollada utilizando una interfaz moderna con Jetpack Compose y sigue principios de Programación Orientada a Objetos (POO) junto con una arquitectura basada en ViewModel.

🚀 Tecnologías utilizadas
Kotlin
Jetpack Compose
Material Design 3
Navigation Compose
ViewModel (MVVM)
Android Studio
GitHub (control de versiones)

▶️ Instrucciones para ejecutar la app
Clonar el repositorio:
git clone https://github.com/priscila0621/TaskFlowUAM.git
Abrir el proyecto en Android Studio
Esperar a que se sincronicen las dependencias
Conectar un dispositivo físico o iniciar un emulador
Ejecutar la aplicación presionando el botón Run
